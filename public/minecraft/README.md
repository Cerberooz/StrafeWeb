# Minecraft item textures

Vanilla Minecraft Java Edition **1.21.4** textures, extracted directly from [Mojang's official client JAR](https://piston-data.mojang.com/v1/objects/a7e5a6024bfd3cd614625aa05629adf760020304/client.jar) and served locally for season kit information. These are original game assets, not AI-generated icons.

The downloaded client was verified against SHA-1 `a7e5a6024bfd3cd614625aa05629adf760020304` from [Mojang's version metadata](https://piston-meta.mojang.com/v1/packages/010c66f4559d4647c282d581a451cda6d45777db/1.21.4.json). Every PNG is copied unchanged from the archive. [SOURCES.json](SOURCES.json) records each archive path and SHA-256 checksum for future verification.

`netherite_chestplate`, `tnt_minecart`, `end_crystal`, `mace`, `tipped_arrow_base`, `tipped_arrow_head` and `clock_00` come from `textures/item/`. The clock is saved as `clock.png`. `heart.png` is `textures/gui/sprites/hud/heart/full.png`.

Textures belong to Mojang/Microsoft. This project is not affiliated with them. The original pixel assets are copied unchanged; the website layers the arrow textures with a red head tint.
